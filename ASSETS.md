# Assets

**Art direction:** Top-down 2D pixel art RPG style using Smallville/Generative Agents asset pack (LimeZu interiors, PixyMoon backgrounds, CuteRPG tilesets). 32px tile grid, chibi character sprites at 48x48 frames. Warm pastoral palette. Camera follows player at 2-3x zoom over the tile world.

## Source Assets (from generative_agents repo)

### Map
- `assets/the_ville.tmx` — Tiled map file (140x100 tiles, 32px)
- `assets/img/the_ville2.png` — Town overview thumbnail (719x513)

### Character Sprites (48x48 frames, RPG Maker VX Ace format)
- `assets/characters/Character_RM_001.png` through `Character_RM_010.png`
- 12 columns x 8 rows per sheet (8 characters, 3 frames x 4 directions each)

### Tilesets (32x32 tiles)
